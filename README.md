# BuSsite

Прототип веб-сайта с функцией "анти-сон". Если пользователь уснет или пропустит кнопку взаимодействия, сработает громкий скример, чтобы разбудить его.

---

## Особенности проекта

- **Отслеживание бездействия:** Скрипт мониторит нажата ли кнопка.
- **Триггер события:** При отсутствии действий в течение некоторого времени активируется звуковой и визуальный скример.
- **Адаптивность:** Корректно работает как на десктопных браузерах, так и на мобильных устройствах.

---

## Стек технологий

- **HTML5** —  разметка страницы
- **CSS3** — стилизация
- **JavaScript (ES6+)** — логика отслеживания событий (OnClick) и таймеры

## Запуск локально

Проект не требует установки серверных зависимостей (Node.js, PHP и т.д.).

1. Склонируйте репозиторий:
```bash
git clone https://github.com/Kievsky332/BuSsite.git
```
2. Перейдите в папку проекта:
```bash
cd BuSsite
```
3. Откройте файл index.html двойным кликом в любом браузере. 
(Рекомендуется: используйте расширение Live Server в VS Code для удобной разработки).
